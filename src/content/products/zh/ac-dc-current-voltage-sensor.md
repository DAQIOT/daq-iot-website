**产品详情**

# **1 产品概述**

![](/images/products/1780900067180664.png)

DAQ-GP-A/DCT/VT系列交直流电流、电压传感器是上海数采物联网科技有限公司生产的一入一出工业级信号变送装置，用于交直流回路电流、电压实时测量。产品采用高精度超微晶铁芯线圈与工业级芯片，采用真有效值测量，精度高、稳定性好、抗干扰能力强。可将交直流电参量转换为DC4~20mA、DC0~5V、DC0~10V等标准模拟量或RS485数字量输出，兼容各类PLC、触摸屏、DCS、工控采集设备，广泛用于电力、通信、环保、机房监控、工业测量、配电监测等领域。

# **3 功能特点**

n 支持穿孔电流输入、端子电流输入、端子电压输入三种方式

n 真有效值测量，精度高、线性度好、温漂小

n 输入/输出/电源三端电气隔离，抗干扰强

n 宽范围交直流供电，适配现场多种电源

n 标准35mm导轨安装，安装便捷、维护简单

n 输出可选：DC4~20mA、0~20mA、0~5V、0~10V、RS485

n 工业级宽温设计，长期稳定可靠

n 支持输入量程、输出信号、供电电压定制

n 过载能力强，满足工业现场恶劣环境

# **5 接口说明及安装**

## **5.1端子定义**

n P+：电源正极

n GND：电源负极/公共地

n OUT+/OUT：模拟量输出正/负

n A：RS485A（仅RS485机型）

n B：RS485B（仅RS485机型）

n NC：空脚，悬空不接线

## **5.2接线注意事项**

n 端子输入：IN两端接入被测交直流电压/电流

n 穿孔输入：被测线缆直接穿过变送器中间穿孔

n RS485通讯：A、B线严禁接反，多台并联地址不可冲突

n 空脚NC一律悬空，禁止接线

## **5.3安装方式**

n 标准35mmDIN导轨卡扣安装

n 安装环境：无强腐蚀、无剧烈震动、通风良好

n 穿孔式线缆保持平直，避免挤压、弯折
