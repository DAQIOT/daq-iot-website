**产品详情**

# **1 软件概述传送带骨料异物检测视觉识别系统（DAQ-BFODS）** 是上海数采物联网科技自研的工业级异物智能检测软件平台。系统通过接入工业摄像头，持续采集传送带、工位等场景的实时图像，并利用内置的 ONNX 深度学习模型，对画面中的异物、石块等目标进行毫秒级自动识别与标注，实现无人值守的智能巡检。

系统支持多摄像头并发采集、本地 SQLite 数据存储、Web 服务接口以及 MQTT / Modbus 数据上传，可与现有 SCADA / MES 系统灵活对接。识别模型支持替换和重新训练，能够适配矿山传送带、粮食分选、工厂流水线等多种不同场景。

![](/images/products/1783303794156412.png)

## **1.1适用场景**

- 矿山/采石场传送带异物（石块、铁器）检测

- 粮食/农产品分选线异物排查

- 工厂流水线产品外观缺陷检测

- 仓储货架异常物体监测

- 其他需要对视频帧做目标检测的工业场景

# **3 主要功能**

**功能模块**

**功能说明**

�� 多路摄像头采集

支持多路摄像头并发采集，可配置采集间隔、触发方式及图像旋转角度。

�� AI 异物识别

基于 ONNX 格式深度学习模型（YOLO系列）实时识别图像中的异物目标，并在画面上标注检测框和置信度。

�� 多级报警通知

支持本地声音报警、短信报警及电话报警，可配置最小触发次数和报警号码。

�� 历史数据查询

所有采集及识别记录存入本地 SQLite 数据库，支持按时间、设备、状态多维度查询与导出。

�� 内置 Web 服务

启动后自动开启 HTTP 服务（默认端口 9998），提供 REST 接口供第三方系统调用。

�� 多协议数据上传

支持 MQTT、Modbus RTU/TCP、MySQL 等多种协议将识别结果上报至上位系统或云平台。

�� 场景适配训练

识别模型（best.onnx + best.names）可替换，通过重新训练适配不同场景，无需修改软件本体。

�� 自动数据清理

可配置历史数据保留天数和最大记录数，防止磁盘空间耗尽。

# **4 系统架构**

系统核心由采集线程池 → AI 识别引擎 → 结果处理三级流水线构成：

- 采集线程按 camera.ini 中设定的 TIMER 间隔定时从摄像头抓取图像帧；

- 图像帧送入 ONNX 推理引擎（调用 weights/best.onnx），完成目标检测；

- 检测结果写入本地数据库，并根据配置触发报警和数据上传。

**摄像头 → 采集线程 → AI识别引擎 → 结果处理 → Web API / MQTT / 报警**

配置文件关系：camera.ini 控制采集参数，DialRecognCfg.ini 控制识别与全局参数，weights/best.onnx 为模型文件。
