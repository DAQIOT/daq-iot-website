**产品详情**

# 1 **产品概述**

![](/images/products/1692840518206866.png)

SC-GP-IRLAN以太网红外抄表器是上海数采物联网科技有限公司推出的针对电表采集DLT645转JSON功能的产品，自动采集 DLT645 仪表的数据，转化为 JSON 格式上发云端服务器。支持 1 个以太网接口、RS485 串口。9~24V 的宽电压的高质量电源设计提供了更好的工业环境适应性，可配备的导轨安装配件适合导轨安装。

# 3 **执行标准**

《Q/GDW 1365—2013 智能电能表信息交换安全认证技术规范》 国网标准

《多功能电能表通信协议 DLT645-2007》 国标

《三相智能电能表型式规范 Q/GDW1356-2013》 国网标准

# 4 **技术参数**

# **4.1外形 **

接口： 485：接线端子； 422：接线端子

电源： 内正外负，标准电源插座；二线端子方式

尺寸： L x W x H =9.4cm×6.5cm×2.5cm

面板灯： 1．ACT：ACT 灯亮绿色时表明有数据正常地在以太网和 RS485 之间传输。 ACT 灯蓝色闪烁时表示有数据从 RS485 返回到以太网。如果数据比较短 则蓝色闪烁时间比较短暂，需要注意查看。

2．LINK：LINK 灯为绿色时表示 RJ45 网线已经接好。LINK 灯为蓝色时，表示 TCP 连接建立或者处于 UDP 模式。

3．POWER：表明串口服务器已经上电。

# **4.2 串口参数**

波特率： 1200~115200bps

校验位： 无, 奇校验, 偶校验, 标记, 空格

数据位： 5～9 位

# ** 4.3 环境要求**

操作温度： -40~85℃

储存温度： -45~165℃

湿度范围： 5~95%相对湿度

# **4.4软件参数**

网络协议： TCP/UDP/ARP/ICMP/DHCP/DNS/HTTP

通信方式： Socket

用户配置： Windows 配置工具 Config tool

# 6 **数据上报通信协议**

UDP/TCP等多种推送方式，

**JSON格式数据报文示例：**

{"Energy":3456.71}

{

}

"Rvalley": 0, //反向谷平电量
