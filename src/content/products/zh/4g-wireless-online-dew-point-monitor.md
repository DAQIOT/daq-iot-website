# 4 **产品特性参数**

## 4.1 **采集特性**

露点量程：-60°~ 60°C （可设置，受环境影响）

测量精度：±2°C（空气中或者N2中）

## 4.2 **电气特性**

工作电源：DC 12V~30V

功耗：小于5W

## 4.3 **通信特性**

无线传输方式：4G/LoRa/WiFi/网线

通信协议：MQTT/TCP/UDP/HTTP/SSL/,可定制其他协议

数据转发：任意公网服务器

服务器中心数量：最多可支持同时向7个云服务器同时上报数据。

心跳包：支持自定义心跳包，可设置为信号强度。

注册包：支持自定义注册包，可设置为IMEI码。

## 4.4 **工作环境**

探头工作温度：-40°~ 80°C

# 7 **数据上报通信协议**

## 7.1 **协议解析说明**

UDP/TCP/MQTT/HTTP等多种推送方式，用户接收数据需提供云端服务器公网IP地址和端口号。

**JSON格式数据报文示例：**

{"IMEI":860344048491162,"Temperture":20,"Humidity":"17.54","DP":"12","ICCID":"1119205006447538"}

**报文解析：**

{

"Temperture": "20.2" // 温度

"Humidity":"17.54" // 湿度

"DP":"12" // 露点

"ID": "860344048491162" // 设备ID

}

协议接收测试

可采用网络调试助手NetAssist进行接收测试。

## 7.2 **协议定制**

如需定制其他通信协议，可联系业务人员沟通。

## 8.2 **用户指定平台**

以阿里云平台对接为例，用户在阿里云物联网平台创建产品和添加设备后，用户需提供一个三元组：{ProduRPMKey , DeviceName , DeviceSecret }和要发布的MQTT主题。

例如三元组的值分别为：

ProduRPMKey = b0FMK1Ga5cp

DeviceName = 862991419835241

DeviceSecret = y7MTCG6Gk33Ux26bbWSpANl4OaI0bg5Q

以OneNet平台对接为例，用户在中移动OneNet平台创建产品和添加设备后，用户需提供产品ID和和设备注册码。

例如：

ID：332590

注册码：DGRUa7Vr9KYGunwJ
