# 1 **产品描述**

![](/images/products/1780889791105240.png)

![](/images/products/1780889818150109.png)

以太网DTU是我司推出的一款高稳定性、高性价比、低功耗的经典双串口服务器。该产品已搭载好外围电路，采用便捷的插拔式接线端子，可直接与485/232串口通信；该产品主频高达240MHz，支持RS-232 和 RS-485 同时工作，内部搭载深度优化的 TCP/IP 协议栈；产品基于网页配置/上位机可视化配置设计结构，用最少的配置帮助你专注于应用，缩短项目开发周期、节约研发成本，方便客户评估测试或直接批量应用。

支持**静态 IP 地址或者 DHCP 自动获取 IP 地址**，同时可为客户提供数据传输、协议解析等功能。

在提供无线数据接入同时，可广泛应用于各个物联网领域，如工业数据采集、智慧农业、电力监控、环保污染监测、智能家居、安全管理、出行娱乐等场景。

静态 IP 是需要用户手动设置，设置的过程中注意同时写入 IP、子网掩码和网关。静态 IP 适合于需要对 IP 和设备进行统计并且要一一对应的场景。

DHCP 主要作用是从网关主机动态的获得 IP 地址、Gateway 地址、DNS 服务器地址等信息，从而免去设置 IP 地址的繁琐步骤。适用于对 IP 没有什么要求，也不强求要 IP 跟模块一一对应的场景。

1 DTU IP地址获取

**IP地址获取**

静态 IP

优点：接入无法分配 IP 地址的设备都能够通过全网段广 播模式搜索到

缺点：不同局域网内网段不同导致不能进行正常的通讯

DHCP

优点：接入路由器等有 DHCP Server 的设备能够直接通讯，减少设置 IP 地址的烦恼

缺点：接入无 DHCP Server 的网络，将无法正常工作
