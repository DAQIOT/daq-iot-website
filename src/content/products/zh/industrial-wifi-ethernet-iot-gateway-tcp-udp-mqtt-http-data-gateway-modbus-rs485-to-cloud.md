# Product Overview


The **Industrial WiFi/LAN IoT Gateway** is a powerful edge communication device designed to connect field devices, PLCs, sensors, meters, and industrial equipment to local networks or cloud platforms.

Supporting **TCP, UDP, MQTT, HTTP, ARP, ICMP, DHCP, and DNS protocols**, the gateway enables seamless data acquisition, protocol conversion, edge computing, and remote monitoring for Industrial IoT (IIoT) applications.

Ideal for smart factories, energy monitoring systems, water treatment plants, utility metering, and industrial automation projects.

# FAQ

### Does the gateway support MQTT?

Yes. The gateway supports MQTT Publish/Subscribe mode and is compatible with most MQTT brokers and cloud platforms.

### Can it collect Modbus RTU data?

Yes. The gateway can collect data from RS485 Modbus RTU devices and upload it via TCP, MQTT, HTTP, or UDP.

### Does it support remote configuration?

Yes. Parameters can be configured locally or remotely through a web-based management interface.

### Can the gateway work without internet access?

Yes. It can operate within a local LAN network and store data locally when the network is unavailable.

### Is OEM branding available?

Yes. OEM and ODM customization services are available, including private labeling, firmware customization, and protocol development.
