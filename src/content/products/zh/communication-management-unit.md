**产品详情**

**1 产品概述**

![](/images/products/1744268498133811.png)

![](/images/products/1714100730110294.jpg)

![](/images/products/1726732652159013.png)

IOT getway 是上海数采物联网科技有限公司推出的一款工业协议转换数据采集网关。 支持 Modbus 转 MQTT+JSON 。支持以 MQTT 的方式连接云端服务器，支持可以界面化配 置， 自主采集 Modbus 仪表/DLT645 智能电表仪表的数据，可转为 JSON 格式数据上传到云 端服务器。同时还支持作为普通的透传的串口服务器和 Modbus 网关。支持 1 个以太网接口。 RS232/485/422 三种类型串口。

4 产品特性参数

4.1 电气特性

供电方式：9~24V 的宽电压 (内正外负，标准电源插座；二线端子方式)

工作功耗：小于 5W

4.2 通信特性

通信协议：MQTT/TCP/UDP/HTTP/ModBus RTU,可定制其他协议

4.3 结构特性

尺寸：长×宽×高=9.4cm×6.5cm×2.5cm

4.4 工作环境

温度 -40~85℃

5 产品核心优势

安装简单，快速部署，助力物联网项目快速落地

支持任意物联网云平台和组态软件，提供数据协议对接

支持阿里云等主流云平台

支持外接多路传感器

6 数据上报通信协议

6.1 协议解析说明

UDP/TCP/MQTT/HTTP 等多种推送方式，用户接收数据需提供服务器 IP 地址和端口号。

JSON 格式数据报文示例，根据具体被采集设备确定报文格式：

{"ID":"866714044842879","XXX":3456.71}

报文解析：

{

"XXX": 3456.71, //被采集物理量

"ID": "860344048491162" //设备 ID

}

6.2 协议接收测试

可采用网络调试助手 NetAssist 进行接收测试。

6.3 协议定制

如需定制其他通信协议，可联系业务人员沟通。
