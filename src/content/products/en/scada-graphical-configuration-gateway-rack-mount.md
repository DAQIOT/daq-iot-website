**Product Details**

SCADA Graphical Configuration Gateway (Rack-Mount) is the rack-mount version of the SCADA graphical configuration gateway, designed for installation in standard cabinets and control rooms. It provides graphical configuration and centralized field data access for SCADA systems in power, water, energy and industrial automation projects.
