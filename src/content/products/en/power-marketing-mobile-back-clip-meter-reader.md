**Product Details**

# 1 Product Brief

The Power Marketing mobile phone back-clip (meter reading manager) is a handheld intelligent device with an embedded security unit. It is fully featured and easy to operate, and can be used with Android devices. The product offers 5G/4G, WiFi, Bluetooth, 1D/2D barcode scanning, modulated infrared, laser infrared, high-frequency RFID, RS485/RS232, power bank and mobile hard disk functions. It also has a built-in hardware security encryption unit and Bluetooth communication software encryption using national cryptographic algorithms, ensuring safe and reliable information transmission. Combining ergonomics and innovative design with a color LCD display, it provides a good customer experience and meets the needs of different application scenarios across multiple industries.

## 8.13 Mobile Hard Disk & Power Bank Function

Mobile hard disk function: use the supplied 3-in-1 data cable; insert the main (single) Type-C connector into the phone and connect the other Type-C connector to the back-clip. The back-clip then acts as a mobile hard disk and the phone reads data from it.

![](/images/products/1780897723181674.png)

Power bank function: use the supplied 3-in-1 data cable; insert the main (single) Type-C connector into the back-clip and connect the other end to the phone (only one phone). The back-clip then acts as a power bank to charge the phone.

![](/images/products/1780897753595716.png)

Note: the supplied 3-in-1 data cable can only be used for charging or data transfer between the phone and the back-clip; never use this cable to connect to a charging head.

# 9 Test App Usage Instructions

## 9.1 First Launch

Copy or download the back-clip apk file to the phone, open the phone file manager, and tap the apk file to install. After installation, find the back-clip program on the phone and tap to launch it. The program icon is shown below:

![](/images/products/1780897805291376.png)

## 9.2 Pairing & Connection

On first launch the program requires permissions to be granted; set them to "allow". Select the back-clip Bluetooth MAC address and tap the State Grid connection. A prompt to enter the PIN code will appear; after entering the PIN code, tap "OK" to complete pairing and connection with the back-clip. After success, the function test interface appears.

![](/images/products/1780897850143171.png)

## 9.3 Device Information & Device Status Query

Tap the "Device Information" item in the function list to query device information and device status.

Tap the "Device Information" button to query the back-clip version, company name, model and other information; tap the "Device Status" button to query the back-clip battery voltage, battery level and other information. See the figure below:

![](/images/products/1780897932190111.png)

## 9.4 Basic Information Settings

This function allows users to customize the back-clip interaction time — the time after which the back-clip automatically powers off when it has not communicated with the phone.

![](/images/products/1780898037151036.png)

Note: enter the corresponding value and tap confirm; the execution result is returned automatically after a successful setting.

## 9.5 Scanning Function

This function is used to scan information. Enter the interface and tap the "Closed" button in the lower-left corner to turn on the back-clip scanning module. After "Success" is prompted, the "Scan" button and the "Continuous scan" radio button appear on the interface.

The "Scan" button performs a single scan; "Continuous scan" tests multiple scans until the radio button is deselected. The scan results are displayed in the parameter and value list, as shown below.

![](/images/products/1780898083836899.png)

## 9.6 RFID Card Reading Function

Place the high-frequency RFID card in front of the back-clip and tap the "Read" button to test reading the card number. The read results are displayed in the parameter and value list, as shown below.

## 9.7 Far Infrared Meter Reading Function

This function is used to read the current data of a meter via far infrared. Enter the interface and tap the "Closed" button in the lower-left corner to turn on the back-clip far infrared module. After "Success" is prompted, the "Read meter" button and the "Continuous scan" radio button appear on the interface.

The "Read meter" button performs a single meter reading; "Continuous meter reading" tests multiple readings until the radio button is deselected. The meter reading results are displayed in the parameter and value list.

Entering this interface defaults to reading with the 07 protocol; select the meter reading data item from the 0000000 drop-down list. To read with the 698 protocol, select the data items in the "698 protocol" drop-down list. The last selected protocol type prevails.

## 9.12 Back-Clip File Upgrade

This function upgrades the back-clip program. Before upgrading, copy the upgrade file (ending with the rbl extension) to the phone's sdcard directory.

Step 1: after entering the upgrade interface, tap "Request upgrade", tap "Select upgrade file" in the pop-up interface, find the file to be upgraded in the phone directory and tap to select it.

![](/images/products/1780898941209293.png)

Step 2: tap "File transfer" and tap the "OK" button in the pop-up dialog to execute; after a successful transfer it prompts that the transfer is complete.

Step 3: tap the "Start upgrade" button, enter the upgrade password "00000000" in the pop-up dialog and tap the "OK" button to upgrade.

# 10 Notes

Do not use chargers and Type-C data cables incompatible with the device, and do not use the supplied dual Type-C cable to connect to a charging head; this may cause charging failure and may lead to fire, explosion or other dangers.

Disconnect the charger from the device when charging is complete or when not charging.

If the charger plug or charger is damaged, do not continue to use it to avoid danger.

Do not perform related operations on the tag while charging.

If the device fails and cannot be used, please contact the manufacturer; do not open the device yourself.
