# FAQ – Specialized Software for IoT & DAQ Devices

### 1\. Which devices can the software identify?

It supports a wide range of IoT meters, data acquisition devices, and industrial sensors across multiple protocols.

### 2\. Does it support multiple communication protocols?

Yes. It supports Modbus, MQTT, OPC UA, TCP/IP, and more for seamless integration with existing systems.

### 3\. Can it monitor devices in real time?

Absolutely. The software displays live data from all connected devices and can trigger alerts based on thresholds.

### 4\. Is it suitable for large industrial networks?

Yes. It is designed to scale for hundreds of devices in complex industrial environments.

### 5\. Can it integrate with SCADA or cloud platforms?

Yes. The software can export data to SCADA, EMS, or cloud-based IoT platforms for centralized monitoring and analysis.

### 6\. How is it installed?

The software runs on Windows/Linux platforms. Installation includes connecting devices via Ethernet, RS485, or wireless networks, followed by automatic detection.
