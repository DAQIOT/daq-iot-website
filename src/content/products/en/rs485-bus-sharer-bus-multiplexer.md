1\. Wiring error: Check whether the connection line is connected correctly and whether there is any wiring error. Make sure the connection line is not short-circuited.

2\. Baud rate setting error: Check whether the baud rate of the connected device is consistent with RS 485 The baud rate parameters on the communication devices are consistent.

3\. The device address is set incorrectly: Check whether the connected device has the correct address set.

4\. Transmission distance is too far: RS 485 The transmission distance of communication is limited. If the distance is too far, the communication connection will fail. Solve this problem by adding a signal booster.
