**Product Details**

# 1 Product Overview

![](/images/products/1789107712204563.png)

SC-LP-3CTLoRa is a passive wireless current sensor integrating high-precision current measurement and temperature monitoring. It transmits data to a receiving device via wireless communication, enabling real-time remote monitoring of the measured circuit's data and early detection of potential safety hazards to ensure electrical safety.

The sensor adopts a dual power supply mode: it can operate by connecting to a CT current signal or via an internal battery, switching adaptively and flexibly. No external power supply is required, reducing maintenance. Its compact shape makes installation convenient and adaptable to various application scenarios.

# 7 Common Troubleshooting

| Fault symptom | Analysis | Solution |
| --- | --- | --- |
| Indicator light does not flash | Insufficient battery power | Check whether the built-in battery has power; if not, replace it. When powered by battery only, it takes about 5 minutes for the indicator to flash. |
| Inaccurate current measurement | Signal input terminal not tightened | Re-tighten the wiring terminal |
| | Transformer failure | Check whether the input signal is consistent with the actual value and whether the transformer cable is open-circuited or damaged; replace the transformer if necessary |
| | Sensor failure | Replace the sensor |
| No data from the receiving device | Incorrect setting | Check whether the sensor ID and other information set on the receiving device are correct |
| | Antenna not properly installed | Check whether the antenna is correctly installed and intact |
| | Distance too far | Verify whether the distance between the sensor and the receiving device is within the nominal range |
