# 1 **Product Overview**

DAQ-SP-PCMCIA-FANUC is a PCMCIA network card launched by Shanghai Data Acquisition IOT Technology Co., LTD. It is designed for data acquisition on FANUC CNC machine tools. It can convert the serial port of FANUC machine tools into an RJ45 network port, enabling communication based on the FOCAS2 protocol.

It is used to enable network communication between FANUC CNC controllers and external systems, allowing program transfer, remote monitoring, and machine data exchange.

It is typically compatible with FANUC CNC controllers that support PCMCIA interface slots. Compatibility may vary depending on CNC series and system configuration.

Yes. It supports fast and stable CNC program upload and download between the CNC machine and network or external devices.
