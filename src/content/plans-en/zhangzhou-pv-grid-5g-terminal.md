## All-in-One 5G Converged Terminal: The Preferred Solution for State Grid Fujian PV Projects

### Project Background: Technical Challenges Under Strict Grid Connection Requirements

In 2025, State Grid Fujian Electric Power issued a letter setting clear requirements for commercial and industrial distributed PV projects. The grid connection plan states that dispatch automation products (PV four capabilities) must meet the following functional requirements:

Dispatch automation: low-voltage 0.4 kV connection to the State Grid requires a telecontrol system for group dispatch and group control

Security encryption: mandatory deployment of vertical encryption devices using the SM2 algorithm

AGC/AVC control: respond to dispatch power commands within 50 ms and distribute them automatically to on-site equipment

Independent centralized control: the owner's monitoring channel must be physically isolated from dispatch
