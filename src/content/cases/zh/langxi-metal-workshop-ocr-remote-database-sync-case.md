一、**项目背景**

郎溪得隆金属表面处理有限公司为一家金属表面处理（电镀、酸洗钝化、化学镀）专业生产企业，车间产线配置专属槽液工艺监控仪表柜，面板共16 路核心工艺仪表（pH 酸碱度仪、ORP 氧化还原电位仪、电导率检测仪、加药泵频率控制器），全程在线监控镀液参数，是保障工件镀层质量、工艺稳定性、生产合规性的核心设备。

此前现场数据管理模式为人工定时手抄记录，由车间巡检人员定时抄录 16 个仪表数值，纸质登记后再人工录入公司管理系统再提交给总公司。数据时效性差、人员运维成本高，不利于工艺优化、参数趋势分析、设备运维追溯。

![](/images/cases/1783409488101511.png)

监控仪表柜

二、**项目技术方案**

本项目针对金属表面处理车间工艺监控仪表柜，基于上海数采物联网科技有限公司(DAQ-IOT)的本地机器视觉图像识别技术为郎溪得隆金属表面处理有限公司实现柜面 16 路仪表数值自动识别、数据校验处理，并实时上传异地存储至外省集团总部SQL Server 2019 数据库，替代传统人工抄表、手动录入模式，实现产线工艺数据无人值守采集与统一归档管理。

![](/images/cases/1783409574141561.png)

三、**项目实施流程**

1、前期现场勘测与硬件选型

项目实施前期完成现场精准勘测：确定 16 路仪表各自数据显示区域实际尺寸、仪表柜整体面板尺寸，测算摄像头最优安装距离与拍摄视角。以此为依据匹配对应摄像头像素、镜头焦距，完成相机硬件选型，保证仪表屏幕画面清晰无畸变、数字字符完整成像，满足视觉识别基础要求。

3、数据上传及储存

**异地数据库部署（总部）**

- 登录总部服务器，连接 SQL Server 服务；

- 新建tiot数据库与tiot数据表；

- 创建专用数据库用户，分配CRUD 增删改查权限；

配置 ODBC 数据源连接，打通本地与总部数据库链路。

四、**项目实施成果**

消除人工抄表、录入带来的读数误差与人为疏漏，提升工艺数据真实性、时效性。实现产线参数全自动不间断采集，所有子公司生产数据统一存储至总部数据库，满足企业数据归档、生产追溯、后续数据分析与数字化管理需求。
