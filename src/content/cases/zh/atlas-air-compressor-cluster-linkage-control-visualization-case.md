**一、项目背景项目时间：** 2026年1月

**客户背景&痛点：**

n 厂区内拥有4台（现场目前为2台，后期增加2台）ATLAS品牌空压机，为生产线提供稳定气源。

n 各空压机独立运行，依赖人工巡检记录运行参数（压力、温度等），数据分散，无法集中监控。

n 设备启停、轮换依赖人工，存在忘记切换、负载不均的风险，影响设备寿命。

n 当一台设备故障时，无法及时自动调整运行策略，可能影响生产气源供应。

n 缺乏历史数据追溯，难以进行能效分析与预防性维护。

**二、项目目标与定制化需求客户希望构建一套集中监控与智能联控系统，实现以下功能**：

1. **数据集中可视化：** 各台机组实时运行状态显示，包括运行时间、低压主机和高压主机的进口温度、出口温度、进口压力、出口压力、油压、油温等控制器上实时采集并集中显示在统一的大屏看板上。

2. **智能轮换控制：** 实现4台设备的自动顺序轮换运行，每6小时(可设置)轮流运行，1台运行，其他3台关闭。均衡设备损耗，延长整体寿命。轮换时间可灵活设置。

3. **按需智能启停：** 根据管网压力自动控制设备启停。当末端压力低于设定下限压力(压力可设置)时，自动启动备用机补充；达到目标压力后，原来主机继续运行，备用机停止，主设备故障停机后,自动踢出，其他设备继续自动顺序控制，实现节能运行。

4. **高可用性保障：** 当运行中的主机发生故障时，系统需能自动将其从运行队列中安全隔离，并自动启用备用设备，保障气源供应不中断。

5. **灵活操控模式：** 保留手动控制功能，可在“自动”与“手动”模式间切换，上限压力与下限压力均可设置，满足特殊情况下的操作需求。

**三、解决方案**

我们为客户提供了一套基于 **“智能工业网关 + 自主研发数据采集平台 + 组态可视化软件”** 的软硬件一体化定制解决方案。

**1. 硬件对接层：**

利用**阿特拉斯空压机数据采集网关（DAQ-GP-AMmodbus）**，通过标准的**Modbus RTU协议**与每台空压机的控制器进行稳定通讯。

网关通过DB九针空压机接口连接空压机面板进行一对多数据采集、协议转换、数据初步处理，并通过**Modbus RTU协议**将数据上传至可本地离线部署的通用工业数据采集系统。

**2. 数据与逻辑核心层：**

部署我司自主研发的**通用工业数据采集系统**，精确解析设备点表，实现对所有空压机参数的秒级实时采集与存储（同时支持各类数据库）。

在系统中内置了**定制开发的联控逻辑引擎**，可靠地执行“自动轮换”、“按需启停”、“故障设备剔除”等核心控制策略，确保逻辑的稳定与准确。

**3. 应用展示层：**

为客户量身定制了**工业组态监控大屏**。大屏设计直观，包含：

**设备状态一览：** 四台设备运行/停止/故障状态一目了然。

**实时数据面板：** 集中展示所有关键温度、压力参数。

**智能联控面板：** 可设置轮换时间、压力上下限，并显示当前主机与队列顺序。

**手动控制面板：** 提供独立的设备启停按钮与手/自动模式切换。

**历史趋势曲线：** 关键参数变化趋势可随时查询，用于故障分析与能效管理。

**自动报警系统：** 设备异常时，会弹出报警信息并记录。

**四、项目成果管理可视化：** 值班人员在工控机处全面掌握各个空压机运行状况，告别了人工巡检抄表，**管理效率提升**。

**控制自动化：** 实现了完全的自动轮换与按需启停，**避免了人为操作失误**，设备利用更均衡，可延长设备整体寿命。

**运行节能化：** 精确的按需启停控制，避免无效运行，**实现了显著的节能效果**。

**系统高可用：** 故障设备的快速隔离与备用设备的无缝接替，**极大保障了生产气源的稳定性**，减少了非计划停产风险。

**维护数字化：** 完整的运行历史数据为设备的**预防性维护**提供了精准的数据支撑，变“故障后维修”为“预警式维护”。
