# 一、 **项目背景**

为积极响应制造业数字化转型与智能制造发展战略，湖北某车身部件有限公司致力于提升其生产车间的精细化管理和运营效率。目前，生产过程中各类关键设备（如冲压、焊接、喷涂机器人等）的实时运行状态、性能指标及效率数据尚未被有效采集和利用，管理层难以量化评估设备的真实利用率（稼动率），无法精准支撑以OEE（全局设备效率）为核心的生产效能分析，制约了生产潜力的进一步挖掘。

# 二、 **项目目标**

本项目核心目标是建立一套稳定、高效的生产设备数据采集与分析系统。通过实时采集设备PLC中的关键数据，实现对设备稼动率、性能开动率、合格品率等OEE核心指标的精准计算与可视化监控，从而为生产决策提供数据支持，发现生产瓶颈，持续优化生产效率。

# 三、 **技术方案概述**

（1）**采集方式：**采用本地化部署方案，确保生产数据不出厂，保障信息安全与网络独立性。

（2）**通信协议：**兼容主流的工业通信协议，主要包括 Modbus TCP 和 OPC UA，以覆盖车间内绝大多数生产设备。

（3）**采集频率：**设定为1秒1次的高频采集，以满足对设备瞬时状态（如启停、故障）的精确捕捉和实时分析需求。

（4）**据存储：**采集到的数据将持久化存储至SQL Server（适用于核心业务数据）和MySQL（适用于高频时序数据或日志数据）关系型数据库中，形成统一的数据资源池，为上层应用提供稳定、可靠的数据服务。

# 四、 **预期价值**

该系统建成后，将为企业提供数据驱动的决策能力，实现生产过程的透明化管理，精准定位效率损失环节，最终达成提升设备综合效率(OEE)、降低停机时间、优化生产节拍的目标。

# 五、 **方案设计**

考虑到要采集的设备种类和通讯协议以及现场施工环境不同，该项目案采用IOT GetWay系列**PLC采集网关**，和**通用工业数据采集系统（DAQ FOR IIOT）配合采集，**将不同种类设备的数据采集并存储到指定数据库供客户分析使用。

**其核心优势兼容性最大化：**网关强大的多协议解析能力，确保不同品牌（如西门子、三菱、欧姆龙等）、不同协议（Modbus TCP/OPC UA）的设备能快速接入，极大提升了项目的实施效率和覆盖范围。

**稳定性最强化：**工业级硬件与专业的采集软件组合，构成了稳定可靠的数据链路，有效抵御工业现场干扰，保障7x24小时不间断的数据供给，为准确的OEE分析提供连续性保障。

**可维护性最优化：**平台的集中管理功能实现了对分散网关的“一站式”监控与配置，极大降低了后期运维的难度和成本。系统具备良好的扩展性，未来新增设备可快速平滑接入。

该选型确保了数据采集环节的高质量与高可靠性，是本项目成功实施的关键技术保障。

## **PLC设备采集方案**

![](/images/cases/1780282354130693.png)

IOT Gateway网关是上海数采物联网科技有限公司推出的一款工业协议转换数据采集网关。网关内置标准采集协议、行业协议、主流PLC、CNC机床、海天注塑机采集协议，支持百余种工业设备的数据采集，无需安装软件，使用浏览器即可进行配置。

支持MQTT、HTTP、ModBus、OPC UA、TCP、数据库、/DLT645智能电表仪表的数据，可转为JSON格式数据上传到云端服务器。同时还支持作为普通的透传的串口服务器和Modbus网关。支持以太网接口/4G/WiFi接口。RS232/485/422三种类型串口。

DAQ for IIOT通用工业数据采集系统是一套运行在边缘计算机上的设备数据采集与管理软件，主要用于对各种仪器设备（PLC、注塑机、数控机床、电表、流量计等）数据的采集、控制、存储、查询、展示以及上传。

- 灵活的传输配置（链路、存储、设备、因子、上传服务）

- 数据采集和上传

- 实时监控（设备、上传）

- 告警配置和监控

- 数据存储和查询（表格、图表、Web API）

- 组态和可视化设计
