Changzhou Jiajue Machinery applied for smart-workshop certification and needed to network its FANUC and Mitsubishi CNC machines. Acquisition via the machine Ethernet ports collects running status, spindle speed, feed, and alarm information, uploading it to a workshop visual dashboard for real-time monitoring and production statistics.
